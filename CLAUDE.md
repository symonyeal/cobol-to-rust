# Workbench contract

One Rust package. Preserve raw program observations; never normalize acceptance bytes. Baseline creation is explicit and cannot be triggered by verification. A blocked or missing required case fails the all-case gate. Keep external upstream source and compiler/run bundles outside this repository. Do not repair a reference program silently.

Run `cargo fmt --check`, `cargo clippy --all-targets -- -D warnings`, and `cargo test --locked` before committing. Live parity requires the pinned Windows reference profile and admitted sources. Record exact tested domains and limitations in reports.

Work and push on `main` as authorized by the owner. Never include local absolute paths or credentials in public artifacts. Maintain `docs/decisions.md` with consequential choices, evidence and claim boundaries for later process writing.
